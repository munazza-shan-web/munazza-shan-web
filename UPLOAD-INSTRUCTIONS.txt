PORTFOLIO UPDATE — HOW TO APPLY

This ZIP contains five replacement files:
- index.html
- style.css
- script.js
- packages.html
- inquiry-form.html

1. Open the munazza-shan-web repository folder through GitHub Desktop.
2. Copy these five files into the repository's main/root folder.
3. Choose Replace the files in the destination when Windows asks.
4. Do not delete your existing assets folder, inquiry-form.html, or Munazza-Shan-CV.pdf.
5. Return to GitHub Desktop.
6. Commit with: Update portfolio for full-stack development
7. Click Push origin.
8. Wait 1–3 minutes, then refresh the GitHub Pages website.

The updated index.html expects these existing images:
assets/dental.png
assets/clinovia.png
assets/loomora.png
assets/sterling.png
assets/aurelia.png
assets/forgecrest.png

If those images already appear in your current portfolio, no asset changes are needed.
